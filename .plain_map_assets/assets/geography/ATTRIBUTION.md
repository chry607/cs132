# Boundary data

Source: James Faeldon, Philippines Administrative Boundaries JSON Maps, MIT license.
https://github.com/faeldon/philippines-json-maps

Pinned revision: `8eeead560246863c8c820c31ca6fbca81a279477` (2024-09-17).
Source folder: `2023/geojson/regions/lowres/`.

The bundled geometry combines the 17 regional province/district collections and rounds coordinates to 4 decimal places for a compact, low-resolution visualization. The original repository derives its boundaries from the Philippine PSGC shapefiles. This vintage is used to align with the 17-region coding in the supplied SOF Public Use File; it is not a claim about current administrative boundaries.

The map shows **regional** statistics. Polygon outlines do not imply province-level survey estimates. Column locations are centroids derived from the regional geometries, not respondents' locations.
